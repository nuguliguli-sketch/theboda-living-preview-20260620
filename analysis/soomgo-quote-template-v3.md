# 숨고 견적서 v3 (평형 3구간 + 접수대행 2만 원 + 사후점검 6만 원)

작성일: 2026-10-14 · 기준: 꼼꼼하자 표시가 17만 원(84㎡ 전후, 접수대행 +5만 원)과 같거나 약간 낮게

## 1. 가격표

| 전용면적 | 진단비 (육안+장비+보고서) | +하자접수대행 | 합계 | 참고: 꼼꼼하자 |

| 84㎡ 이하 | **160,000** | +20,000 | **180,000** | 170,000 + 50,000 = 220,000 |
| 114㎡ 이하 | 180,000 (안) | +20,000 | 200,000 | — |
| 114㎡ 초과 | 별도 문의 | +20,000 | — | — |

| 추가 서비스 | 금액 | 참고 |
|---|---|---|
| 하자접수대행 | 20,000 | 경쟁사 모두 50,000 |
| 사후점검 | 60,000 | 홈즈체크 75,000 / 꼼꼼하자 별도 비용, 6가구 이상·화수목만 |
| 같은 단지 3세대 이상 묶음 예약 | 대표 예약자 1세대 10,000원 할인 | 10월 고용의 68%가 단지 묶음 |

- 숨고 견적의 **금액 칸에는 고객 평형의 진단비만** 넣습니다(84㎡ → 160,000원).
- 60~84㎡(74㎡ 타입 포함)는 84㎡ 구간 16만 원입니다.
- 114㎡ 구간 18만 원은 확정 전입니다. 10월 장부에서 113㎡는 17만~21만 원에 성사됐습니다.

## 2. 자주 쓰는 첫 견적서 (붙여넣기용)

```
[84㎡ 이하 16만원 · 하자접수대행 +2만원 · 사후점검 6만원]
육안점검 + 장비점검 + 보고서까지 포함된 금액입니다.

안녕하세요, 주택 점검 서비스 더보다입니다.
국제 주택검사관(InterNACHI® CPI) 자격 보유 인스펙터가 직접 점검합니다.

✔️ 평형별 진단비 (육안+장비+보고서)
· 59㎡ 이하 : 15만원
· 84㎡ 이하 : 16만원
· 114㎡ 이하 : 18만원
· 114㎡ 초과 : 별도 문의

✔️ 하자접수대행 +2만원 (선택)
점검 결과를 시공사 하자접수 앱 방식에 맞춰 대신 등록해드립니다.
직접 접수하실 경우 공간별 하자 사진과 내용을 정리해서 전달드립니다.

✔️ 사후점검 6만원
시공사 보수 후, 기존 하자 번호 기준으로 보수 완료 / 미보수 / 재보수 필요 항목을 다시 확인해드립니다.

✔️ 점검 항목
· 육안: 마감·도배·마루·타일·창호·가구·욕실·실리콘 등 세대 전체
· 장비: 열화상(단열·누수), 수평/수직, 욕실 구배, 콘센트, 공기질 등
· 보고서: 하자 번호·위치·사진(원경/근경) 정리 + 3D VR 기록(후기 작성 시)

✔️ 같은 단지 3세대 이상 함께 예약 시 대표 예약자 1만원 할인

사전점검 날짜와 평형 알려주시면 가능한 시간 바로 확인드릴게요.
```

## 3. 채팅 응대 문구

**"접수대행은 뭐예요? 꼭 해야 하나요?"**
```
선택 사항입니다.
시공사마다 하자접수 앱이나 양식이 달라서, 하자 수십 건을 사진과 함께 하나하나 등록하는 데 시간이 꽤 걸립니다.
접수대행(2만원)을 선택하시면 점검한 내용을 저희가 앱에 직접 등록해드리고,
직접 하실 경우에도 공간별 사진과 내용을 정리해서 전달드리니 그대로 올리시면 됩니다.
```

**"사후점검은 언제, 어떻게 해요?"**
```
사후점검은 시공사 보수가 끝난 뒤, 보통 입주 1~2주 전에 진행합니다.
사전점검 때 정리한 하자 번호를 기준으로 하나씩 대조해서
보수 완료 / 일부 보수 / 미보수 / 재보수 필요로 나눠 정리해드리고,
재접수가 필요한 항목은 따로 표시해드립니다.
비용은 6만원이며, 시공사 보수 일정이 나오면 편하게 연락 주세요.
```

**"다른 데보다 비싸요 / 깎아주세요"**
```
안내드린 금액은 평형별 기준 금액이라 개별 할인은 어렵습니다.
대신 하자접수대행이 2만원이라, 접수대행까지 포함하면 다른 업체보다 부담이 적은 편입니다.
같은 단지에서 3세대 이상 함께 예약하시면 대표 예약자분께 1만원 할인해드리고 있습니다.
```
